# ДЕРЖИ

Приложение, которое я могу сделать один: без 3D-художника, без бэкенда, без нейросети в рантайме.

**Зажми круг. Не отпускай.** Сегодня у всего интернета одна и та же колода фейковых уведомлений (мама, банк, бывший, начальник). Первый замер дня — официальный. Потом кидаешь сетку в чат, как Wordle.

Рабочая ссылка: https://ramza107.github.io/Tamagochi/

Hard refresh: `Ctrl+Shift+R`.

## Почему это может разлететься

1. Правило объясняется за секунду.
2. Все играют **одну колоду дня** (Москва, дата) — есть о чём спорить в чате.
3. Результат — копируемый текст, не скрин «посмотри какой у меня питомец».
4. Картинку персонажа рисовать не надо: продукт — нервы и типографика.

## Локально
