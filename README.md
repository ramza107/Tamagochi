# Pulsepet

Питомец, которого кормит твоя жизнь.

## Идея

**Nuri** — мягкий моховый камешек с янтарным «ядром-пульсом» в груди. Он не яйцо и не кот: живой барометр твоего дня. Сон, шаги и экранное время меняют цвет, позу и короткие письма от него.

## Сейчас (MVP)

- Экран с Nuri, 4 настроения, 3 стадии роста
- Симулятор метрик дня (заглушка под HealthKit)
- Локальное сохранение
- Expo (iOS / Android / Web)

## Позже на Mac

- HealthKit + Screen Time
- Lock Screen widget / Live Activity
- Пуши и App Store

## Запуск

```bash
npm install
npm run web
# или
npx expo start
```

На телефоне: Expo Go → сканируй QR.
